# iphone-duo-price-notes

Price-ladder notes: what each iPhone Duo storage upgrade costs in four regional Apple stores (US, UK, Hong Kong, mainland China), in local currency, with the step and per-GB arithmetic.

The page is a single static `index.html` (no JS, no cookies). Prices are a dated snapshot; check the live store before relying on them.

Live regional table: [iPhone Duo regional price comparison](https://iphoneduo.io/price) (independent guide, not affiliated with Apple).
